# Youhe Bain 1: Others' Circumstances

Консольный текстовый триллер о скаме, паранойе и выборе.

Язык: Python 3.14+
Платформа: Windows
Статус: Beta

---

## О игре

Вы — обычный человек, пытающийся выжить в мире абсурдных корпораций, назойливых мошенников и странных звонков. Ваша цель проста: заработать очки, сохранить рассудок и не попасть в неприятности.

Когда на горизонте появляется загадочный хакер Толя, перед вами встает выбор: остаться в безопасности или войти в мир теневого скама, где одна ошибка может стоить вам всего.

Жанр: Текстовый триллер / Симулятор выживания / Криминальная драма
Время прохождения: 45-60 минут (одно прохождение)
Количество концовок: 5 уникальных финалов

---

## Особенности

- Живой мир: более 10 уникальных диалогов с запоминающимися персонажами.
- Экономика: баланс между рутинными действиями и рискованными решениями.
- Мини-игры: рыбалка и забивание гвоздей с системой проверки реакции.
- Случайные звонки: непредсказуемые события, влияющие на ресурс времени.
- Система выборов: каждое решение фиксируется и влияет на доступные концовки.
- Автосохранение: прогресс сохраняется автоматически в формате JSON.
- Атмосферное сопровождение: аудиотреки в ключевых сюжетных моментах.

## Установка

### Вариант 1: Готовый исполняемый файл (Рекомендуется)

1. Перейдите в раздел Releases репозитория: https://github.com/vexikoff/youhebain1/releases
2. Скачайте архив `Youhe.Bain.1.Others.Circumstances.zip`
3. Распакуйте архив в любую удобную папку
4. Запустите исполняемый файл внутри архива

### Вариант 2: Из исходного кода

Требования:
- Python 3.14 или выше
- Операционная система Windows (для корректной работы библиотеки msvcrt)

Шаги установки:
1. Клонируйте репозиторий:
```cmd
git clone https://github.com/vexikoff/youhebain1.git
cd youhebain1
```

2. Установите зависимости:
```cmd
pip install -r requirements.txt
```
3. Запустите игру:
```cmd
python main.py
```

## Управление

- Цифры 1-9: Выбор действия в главном меню
- Цифра 0: Специальные действия (например, звонок Толе)
- Клавиша Q: Открыть магазин
- Enter: Подтверждение действий и управление в мини-играх

---

## Механики

Основная петля геймплея:
- Выполняйте бытовые действия для заработка очков.
- Ожидайте случайных звонков от корпораций и мошенников.
- Принимайте решения, которые влияют на развитие сюжета.
- Копите очки на критически важные покупки (MearePhone, база данных).
- Доживите до 7-го дня для ключевой встречи с Толей.

Ключевые решения:
- Купить базу данных у Толи (80 очков): определяет доступные ветки скама.
- Поехать к Толе или остаться дома: определяет уровень физической и цифровой безопасности.
- Сдать Толю полиции: путь паранойи и неизбежного финала.
